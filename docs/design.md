# Interface design brief

Decided with the project owner through three rounds of multiple-choice questions (2026-10-14).

| Topic | Choice |
| --- | --- |
| Audience | Citizens first; the full legal detail one click away (for students and lawyers) |
| Mood | Moroccan heritage with institutional seriousness |
| Colours | Navy and gold on ivory (light); deep navy with gold (dark). Few colours |
| Theme | Light and dark, following the device, with a toggle |
| Arabic type | Modern: Tajawal / Cairo |
| Identity | Gold 8-point zellige star with scales, next to «قانون» and "Qanoun AI" |
| Home screen | The question box first; many options around it; topic tiles (Labour, Family, Consumer, Personal data) offer example questions as a side option, not the main path |
| Citations | Clickable [1] [2] chips in the answer; the full official article opens in a side panel |
| Features | Live progress steps; copy / share the answer with its citations; interface language switch (Arabic, French, Darija) with RTL/LTR flip; history of questions on the device |
| Motion | Rich and classy (staggered reveals, zellige pattern, turning star while thinking), calm when the device asks for reduced motion |
| Honesty | Always visible: general legal information, not legal advice; unverified answers are flagged |
